# Commands

- `ai status` — live stack and inference telemetry
- `ai gpu` — detailed GPU monitor
- `ai models` — inventory and physical disk footprint
- `ai doctor` — diagnostics, logs, errors, crashes and reports
- `ai logs [service]` — centralized log viewer
- `ai model list|loaded|info|load|unload` — conservative model control
- `ai benchmark --backend ... --model ...` — repeatable inference benchmark
